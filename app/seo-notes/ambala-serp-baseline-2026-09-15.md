# Ambala SERP baseline — 2026-09-15

Public web search before launch showed the dominant organic results for high-intent Ambala used-car queries were large marketplaces such as ZigWheels, CarDekho, CarWale, OLX, Cars24 and Spinny. ROHILLA DRIVE did not appear in the sampled web results, and a local-business search did not return a clear ROHILLA DRIVE / Rohilla Multibrand Cars business entity.

This baseline means the first objective is indexation + entity recognition + local relevance, followed by authority/review growth. A top-two ranking cannot be guaranteed by on-site code alone.
